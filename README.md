# Product Catalog Hub

A modern and responsive product catalog website built with React and TypeScript.

The project focuses on a clean user interface, smooth animations, responsive design, and a simple browsing experience across desktop and mobile devices.

## 🌍 Live Demo

Link: **[View the live website](https://2day0nly.pages.dev)**

## 📚 About the Project

This project was created as part of my practical web development experience.

The goal was not only to build the website itself, but also to practice a complete development and deployment workflow — from working with React and TypeScript to version control, production builds, and cloud deployment.

## ✨ Features

- Modern and minimal UI
- Responsive design
- Smooth animations and interactions
- Product catalog interface
- Multi-language support
- Optimized production build
- Deployed globally with Cloudflare Pages

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- CSS
- Git & GitHub
- Cloudflare Pages

## 🚀 Deployment

The project is deployed using Cloudflare Pages with automatic deployments from the GitHub repository.

The workflow is:

`Development → Git → GitHub → Cloudflare Pages → Production`
